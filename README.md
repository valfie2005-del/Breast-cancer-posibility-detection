# 🩺 Breast Cancer Data Analytics Project

## 📌 Overview

This project focuses on analyzing breast cancer data to identify patterns, trends, and key indicators that help distinguish between malignant and benign tumors. Using data analytics and machine learning techniques, the project aims to support early diagnosis and data-driven medical insights.

---

## 🎯 Objectives

* Analyze breast cancer patient data to uncover meaningful insights
* Identify important features influencing cancer diagnosis
* Perform data preprocessing and exploratory data analysis (EDA)
* Build predictive models for cancer classification
* Visualize patterns and correlations within the dataset

---

## 📂 Dataset

* **Source:** Kaggle (Breast Cancer Dataset)
* **Data Type:** Structured medical data
* **Target Variable:** Diagnosis (Malignant / Benign)
* **Features Include:**

  * Mean radius, texture, perimeter, area
  * Smoothness, compactness, concavity
  * Symmetry and fractal dimensions

## 📌 Key Insights

* Data normalization significantly improves model performance
